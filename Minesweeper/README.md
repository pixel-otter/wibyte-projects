Info about the field has revealed:

- There are 600 mines on it. Scattered randomly
- Each Mine detonates in an area of 1 square kilometer

However, our scientists have put together a high energy ray. This ray will reveal the number of bombs adjecent to the tile and its neigbhors and be able to have a prescision range of 1 km. allowing it to find out which neighbhors are bombs.
The downside-of course, is that it requires a peculiar fuel source. A rare radioactive isotope, luckily the field is rich in it. But proximity to the bombs would decay it so it would only be found where there are no nearby bombs. We can convert them into energy and we need 500 to run a single high power sonar.
