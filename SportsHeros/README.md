# Sports Heros
This project will take info from two major sporting events. The **Chess World Championship** and **Chess World Cup**
# Categories
The categories in the data are:
- and/or either of them
- won both of them
- won Chess World Championship but not Cup
- won Chess World Cup but not Championship
- won one but not both
- All streaks for players

### Go to *analysis.dat* for the data.
